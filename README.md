## 5岁小朋友数学题程序
新增了一个适合5岁小朋友的数学练习脚本：`kid_math_game.py`。

### 玩法
- 随机生成 10 以内加减法
- 输入数字作答
- 输入 `q` / `quit` / `退出` 可以结束游戏
- 自动统计答题数量和正确率，并给出鼓励

### 运行方式
```bash
python3 kid_math_game.py
```
